# javascript-lotto-precourse

---

## 기능 요구 사항

간단한 로또 발매기를 구현한다.

- [ ] 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
  - [ ] 로또 번호의 숫자 범위는 1~45까지이다.
- [ ] 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- [ ] 당첨은 1등부터 5등까지 있으며, 당첨 기준과 금액에 부합해야 한다.
- [ ] 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 하며, 로또 1장의 가격은 1,000원이다.
- [ ] 당첨 번호와 보너스 번호를 입력받은 후 -> 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- [ ] 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시키고 **해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받는다.**

## 과제 진행 요구 사항

- [ ] package.json 파일은 변경할 수 없으며, 제공된 라이브러리와 스타일 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- [ ] 자바스크립트 코드 컨벤션을 지키면서 프로그래밍한다.
- [ ] indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
- [ ] 3항 연산자를 쓰지 않는다.
- [ ] 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다. → 함수(또는 메서드)가 한 가지 일만 잘 하도록 구현한다.
- [ ] Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
- [ ] else를 지양한다. → 어느 경우에 쓰는 것이 적절한지 스스로 고민해본다.
- [ ] 구현한 기능에 대한 단위 테스트를 작성한다. 단, UI(System.out, System.in, Scanner) 로직은 제외한다.
- [ ] @woowacourse/mission-utils에서 제공하는 Random 및 Console API를 사용하여 구현해야 한다.
- [ ] Lotto 클래스는 제공된 Lotto 클래스를 사용하여 구현해야 한다.

  - [ ] 0 이하이거나 소수 입력일 경우

- [ ] 2. 당첨 번호 입력 및 검증

  - [ ] 쉼표 구분자가 아닌 경우
  - [ ] 입력된 숫자가 6개가 아닌 경우
  - [ ] 숫자가 아닌 문자를 입력 받았을 경우
  - [ ] 번호가 1~45 사이가 아닌 경우

- [ ] 3. 보너스 번호 입력 및 검증

  - [ ] 1~45 범위의 중복 없는 숫자 6개 랜덤 생성
  - [ ] 생성된 번호를 오름차순으로 정렬
  - [ ] Lotto 클래스의 인스턴스로 저장

- [ ] 발행한 로또 목록 출력

- [ ] 당첨 번호와 보너스 번호를 이용해 당첨 내역 계산

  - [ ] 각 로또의 일치 개수를 계산
  - [ ] 보너스 번호 일치 여부 판단
  - [ ] 일치 개수와 보너스 여부로 등수 판단
  - [ ] 등수별 당첨 횟수 집계

- [ ] 당첨 내역 출력

- [ ] 수익률 계산

  - [ ] totalPrize = 각 등수별 (당첨 금액 × 당첨 횟수)
  - [ ] profitRate = (totalPrize / purchaseAmount) \* 100
  - [ ] 소수점 둘째 자리 반올림

- [ ] 수익률 출력

## 프로그래밍 흐름

1. 로또 구입 금액을 입력받는다.

2. 로또 구입 금액을 검증하는 메서드를 실행한다.
   2-1. 숫자가 아닌 문자를 입력받았을 경우

   - 문자를 입력 받았다고 [ERROR] 처리하고 다시 입력

   2-2. 1000원으로 떨어지지 않는 경우

   - 1000원 단위로 입력 받는다고 [ERROR] 처리하고 다시 입력

3. 발행한 로또 수량에 따라 로또를 발행한다.
   3-1. 로또 수량에 따른 로또를 발행하는 함수를 실행한다.

   - 입력받은 로또 수량만큼 반복하면서 로또를 발행한다.

   - LottoGenerator 클래스를 통해서 1~45 사이의 중복 없는 6개 번호를 생성하고, 번호를 오름차순으로 정렬한 뒤, 해당 번호로 Lotto 인스턴스를 생성한다.

4. 발행한 로또 수량 및 번호를 출력하는 함수를 실행한다.

5. 당첨 번호를 입력받는다.

6. 당첨 번호를 검증하는 메서드를 실행한다.
   6-1. 당첨 번호 구분자가 쉼표가 아닌 경우

   - 기본 구분자가 쉼표라고 [ERROR] 처리하고 다시 입력

   6-2. 당첨 번호 갯수가 6개가 아닌 경우

   - 당첨 번호 갯수가 6개가 아니라고 [ERROR] 처리하고 다시 입력

   6-3. 당첨 번호가 숫자가 아닌 문자를 입력 받았을 경우

   - 문자를 입력 받았다고 [ERROR] 처리하고 다시 입력

   6-4. 당첨 번호가 1~45 사이가 아닌 경우

   - 당첨 번호가 1~45 사이여야 한다고 [ERROR] 처리하고 다시 입력

7. 보너스 번호를 입력받는다.

8. 보너스 번호를 검증하는 메서드를 실행한다.
   8-1. 숫자가 아닌 문자를 입력 받았을 경우

   - [ERROR] 처리하고 다시 입력

   8-2. 여러 개 입력 받았을 경우

   - [ERROR] 처리하고 다시 입력

   8-3. 보너스 번호가 당첨 번호와 중복될 경우

   - [ERROR] 처리하고 다시 입력

9. 당첨내역을 계산하는 함수를 실행한다.
   9-1. 로또 발행 갯수만큼 반복하면서 로또 발행 배열과 당첨번호 배열을 비교한다.
   9-2. 일치하는 갯수를 구한 후 일치 개수와 보너스 여부로 등수를 판단하고, 등수별 당첨 횟수를 누적한다.

10. 당첨내역을 출력하는 함수를 실행한다.

11. 수익률을 계산하는 함수를 실행한다.
    11-1. 각 등수별 당첨 금액과 당첨 횟수를 곱한다.
    11-2. 각 등수별 당첨 금액과 당첨 횟수를 곱한 결과에 내가 산 금액을 나누고 100을 곱한다.
    11-3. 소수점 둘째 자리까지 반올림한다.

12. 수익률을 출력하는 함수를 실행한다.
